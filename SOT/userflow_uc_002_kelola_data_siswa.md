# UC-002 Kelola Data Siswa

## Aktor

Guru

---

## Tujuan

Mengelola data siswa.

---

## Main Flow

1. Guru membuka Dashboard.
2. Memilih menu Data Siswa.
3. Sistem menampilkan daftar siswa.
4. Guru menekan tombol Tambah.
5. Guru mengisi biodata.
6. Guru mengunggah foto.
7. Guru menekan Simpan.
8. Sistem memvalidasi data.
9. Sistem menyimpan data.
10. Daftar siswa diperbarui.

---

## Alternative Flow

Data belum lengkap.

NIS sudah digunakan.

---

## Exception Flow

Upload gagal.

Server error.

---

## Post Condition

Data siswa berhasil disimpan.

---

## Acceptance Criteria

✓ Data tampil.

✓ Data dapat diedit.

✓ Data dapat dihapus.
